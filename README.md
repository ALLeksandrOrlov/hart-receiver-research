# Исследование алгоритма приёма сигналов HART FSK и C8PSK

Стенд на Python для FSK и C8PSK. Берём байты из текстового файла, превращаем
в сигнал, пропускаем через канал и декодируем обратно. Приёмник сам определяет
режим по сигналу.

## Установка

Нужны Python 3.11+ и NumPy. Все команды ниже выполняются из корня проекта.
Библиотеки ставим в виртуальное окружение:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

В Windows вместо первых двух команд:

```powershell
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
```

Дальше везде используем `python` из активированного окружения. При новом
открытии терминала окружение нужно снова активировать. Для выхода — `deactivate`.

## Быстрый запуск

Сначала FSK, команда 0 — чтение идентификатора устройства:

```sh
python transmit.py samples/fsk_command_0.txt tx.npz --mode fsk
python channel.py tx.npz rx.npz --pole-hz 4000 --snr-db 12 --seed 1
python receive.py rx.npz decoded.txt --compare samples/fsk_command_0.txt
```

В `decoded.txt` должны оказаться исходные байты. Аргумент `--compare`
проверяет их совпадение; ошибка приёма или несовпадение дают ненулевой код выхода.
Существующие выходные файлы защищены от перезаписи. Для повторного запуска
добавьте `--force` или выберите другое имя файла.
При `--force` старый результат удаляется перед обработкой; если она завершится
ошибкой, старый файл не останется под видом нового.

Теперь C8PSK, команда 3 — чтение динамических переменных и тока петли:

```sh
python transmit.py samples/c8psk_command_3.txt tx_c8.npz --mode c8psk
python channel.py tx_c8.npz rx_c8.npz --pole-hz 4000 --snr-db 12 --seed 1
python receive.py rx_c8.npz decoded_c8.txt --compare samples/c8psk_command_3.txt
```

В примерах стоят параметры опыта из статьи: полюс RC-канала 4000 Гц и SNR
12 дБ. Seed `1` выбран здесь для воспроизводимости; в статье он не указан.

Входной текст содержит один полный кадр HART: HEX-байты через пробел,
включая разделитель, адрес, команду, длину данных и XOR-контрольную сумму.
Преамбулу, биты чётности и служебные символы добавляет передатчик.
Допускаются переносы строк и комментарии после `#`. Выход приёмника — тот же
кадр без преамбулы и служебных символов.

## Примеры команд

В `samples/` лежат шесть готовых запросов универсальных команд HART:

| Команда | Что запрашивает | Файлы |
|---|---|---|
| 0 | Идентификатор устройства | `fsk_command_0.txt`, `c8psk_command_0.txt` |
| 1 | Основную переменную | `fsk_command_1.txt`, `c8psk_command_1.txt` |
| 3 | Динамические переменные и ток петли | `fsk_command_3.txt`, `c8psk_command_3.txt` |

Например, запрос команды 0 для FSK:

```text
02 80 00 00 82
```

У команды 0 короткий адрес, у команд 1 и 3 — условный длинный
адрес. При изменении байтов нужно пересчитать XOR; передатчик проверяет кадр.
Для FSK и C8PSK используются разные разделители, поэтому берите файл нужного
режима. Каждый байт записывается двумя HEX-цифрами.

## Канал и помехи

Канал сначала фильтрует сигнал однополюсным RC-фильтром, затем добавляет
белый гауссов шум. SNR считается по мощности сигнала на активном участке
после фильтра; шум присутствует во всей записи, включая паузы.

| Аргумент | Что задаёт | По умолчанию |
|---|---|---|
| `--pole-hz` | Частота полюса, Гц | `4000` |
| `--snr-db` | Отношение сигнал/шум, дБ | `12` |
| `--seed` | Начальное состояние генератора шума | `1` |
| `--clean` | Передача без фильтра и шума | выключено |

Чистый проход для проверки цепочки:

```sh
python channel.py tx.npz rx_clean.npz --clean
python receive.py rx_clean.npz decoded_clean.txt --compare samples/fsk_command_0.txt
```

`--clean` задаётся отдельно от частоты полюса и SNR.

## Что внутри

Запускаемых скриптов три: `transmit.py`, `channel.py`, `receive.py`.
В `hart_receiver/` лежат их внутренние модули. Сигнал хранится в `.npz`:
`samples` — вещественные отсчёты напряжения в вольтах, `sample_rate` —
25600 Гц. Один файл содержит одну передачу.

У передатчика по умолчанию FSK имеет размах 200 мВ, C8PSK — уровень −6 дБм
относительно нагрузки 500 Ом. Уровень меняется через `--fsk-mvpp` или
`--c8-dbm`, начальная фаза — через `--phase` в радианах. У приёмника включена
компенсация однополюсного канала C8PSK; отключение — `--no-equalizer`.

У приёмника `--quantized` включает 8-битный АЦП и 10-битные таблицы NCO/DFT.
Диапазон АЦП выбирается автоматически или задаётся через `--adc-full-scale`
в вольтах.

Чтобы сохранить промежуточные сигналы:

```sh
python receive.py rx_c8.npz decoded_trace.txt --quantized --trace stages.npz --compare samples/c8psk_command_3.txt
```

В `stages.npz` находятся энергии на 1600/4800 Гц, для FSK — `s2`…`s6`,
для C8PSK — `c8_constellation`. На рисунке 8b статьи изображён `4*s5`.
Все аргументы можно посмотреть через `python имя_скрипта.py --help`.

Приёмник основан на статье Jin Zhenghua, Wang Hong, Yang Zhijia,
[Backward Compatible Receiver Structure for C8PSK HART (2010)](docs/jinzhenghua2010.pdf).
